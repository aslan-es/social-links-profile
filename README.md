# Social Links Profile

## 📌 About The Project

Hello! 👋

This project marks my first step back into frontend development after about a 6-month break. I decided to restart my learning journey, and to warm up and review the basics, I chose this Newbie-level challenge from [Frontend Mentor](https://www.frontendmentor.io/).

This mini-project is purely for practice and doesn't include any complex logic or advanced features. It's simply a fun exercise in building a UI component using HTML and CSS to get back into the coding rhythm and pave the way for becoming a professional frontend developer. 🚀

## 🛠️ Built With

- Semantic HTML5 markup
- CSS custom properties (Variables)
- Flexbox
- Mobile-first workflow
